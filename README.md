# ИАС учебно-методических материалов

Исходный код информационной аналитической системы для работы с материалами электронной библиотеки.

## Состав

- `biblio_parser` — сервис парсинга
- `ai_service` — AI-сервис
- `server` — backend (Node.js)
- `client` — frontend (React)

## Запуск

См. конфигурационные файлы `.env.example` в каждом сервисе.
