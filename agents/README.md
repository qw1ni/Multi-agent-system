# Модуль мультиагентной системы

Ветка для разработки агентов поверх ИАС учебно-методических материалов.

## Планируемые агенты

| Агент | Назначение |
|--------|------------|
| `parser_agent` | запуск и контроль сбора данных из электронной библиотеки |
| `analyst_agent` | анализ данных в БД (статистика, покрытие, аномалии) |
| `reporter_agent` | формирование отчётов (Excel / Word / PDF) |
| `orchestrator` | координация запуска агентов и обмен результатами |

## Связь с основным проектом

- `../biblio_parser` — существующий сервис парсинга
- `../server` — backend ИАС
- `../ai_service` — AI-сервис (поиск / эмбеддинги)
- `../client` — интерфейс

Разработка ведётся в ветке `agents`, в `main` попадает после проверки.
